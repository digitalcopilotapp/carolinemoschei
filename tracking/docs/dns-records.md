Open a support ticket with Hostinger requesting:

This is critical for email deliverability. Gmail and Outlook check PTR records.

## Verification

```bash
# Check A records
dig +short mail.digitalcopilot.app
dig +short campaigns.digitalcopilot.app

# Check MX
dig +short MX digitalcopilot.app

# Check SPF
dig +short TXT digitalcopilot.app

# Check DMARC
dig +short TXT _dmarc.digitalcopilot.app

# Check DKIM
dig +short CNAME stalwart._domainkey.digitalcopilot.app

# Check PTR (after Hostinger configures it)
dig -x [KVM_IP] +short
```

## Adding New Domains

For each new project domain that sends email:

1. Add A record for `mail.newdomain.com` → [KVM_IP]
2. Add MX record for `newdomain.com` → `mail.digitalcopilot.app` (priority 10)
3. Add SPF TXT: `v=spf1 a mx ip4:[KVM_IP] ~all`
4. Add DMARC TXT: `v=DMARC1; p=quarantine; rua=mailto:dmarc@digitalcopilot.app`
5. Configure domain in Stalwart admin panel (auto-generates DKIM)
6. Add DKIM CNAME as shown in Stalwart admin
