## NOTAS DE OTIMIZACAO PARA ANDROMEDA 2026

1. **Diversidade de copy e essencial** — Andromeda penaliza similaridade. Usar angulos diferentes por ad set
2. **Primary text ate 125 caracteres aparece sem "ver mais"** — as primeiras 2 linhas sao o HOOK
3. **Headline max 40 chars** para nao cortar no mobile
4. **Testar 3-5 headlines por ad** com Advantage+ Creative
5. **Emojis com moderacao** — podem aumentar CTR mas excessso reduz credibilidade
6. **Copy curta (Copy 08/09) para Stories/Reels**, copy longa (Copy 01-07) para Feed
7. **Cada copy deve ter um angulo radicalmente diferente** para alimentar o Andromeda com diversidade
