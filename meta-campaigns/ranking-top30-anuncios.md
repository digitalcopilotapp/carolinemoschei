## Notas para Implementacao

1. **Priorizar Stories (9:16)** como formato principal — 90% do inventario Meta e vertical
2. **Testar Dark vs White** como variantes no mesmo ad set — Advantage+ seleciona o melhor
3. **Nao rodar variantes (VAR) junto com seus pares originais** no mesmo ad set — similarity penalty
4. **Copy curta (Copy 08) para Stories**, copy longa (Copy 01-07) para Feed
5. **Rotacionar criativos a cada 2-3 semanas** para evitar creative fatigue
6. **Monitorar CPM** — se subir, Andromeda esta detectando similaridade
7. **Pasta 03-Solucao** usa encoding especial (ç) no nome da pasta no filesystem
